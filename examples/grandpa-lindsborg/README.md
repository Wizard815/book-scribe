# Grandpa test: "Everett of Lindsborg", five chapters with pictures, researched history, PDF family documents and a family tree

A writer agent playing Walter (79, half-sighted, voice-first) and a model agent standing in for the language model drove the real app through
three rounds; after each round the missing logic was added (see `docs/CAPABILITIES.md`). This is the book from round 3.

* `family-files/`: the fictional PDFs (draft card, letter from France, obituary, passenger list) and the GEDCOM family tree that were uploaded.
* `book.html`, `book.epub`: exported by voice. `chapters/`, `images/`, `bible/`: what the app saved.
* `screenshots/`: the paged reader at 1920x1080 (two-page spread, 200%).
* `writer-notes-round3.md`: the writer agent's own notes and PASS/FAIL list.

Honest notes: the pictures are drawn stand-ins and the history came from a mock Wikipedia written for this test, so check facts before using any
of it. The writing is the stand-in model's, not a real model's.
