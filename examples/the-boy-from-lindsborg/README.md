# The Boy from Lindsborg: a six-chapter example with an old photograph

Written through Book Scribe by a writer agent playing a half-sighted woman (talks, rarely looks) about her great-uncle Everett Lund, a Kansas
farm boy in the 35th Division in the First World War, with a model agent standing in for the language model.

* `book.html` / `book.epub`: the book as exported by voice ("save my book as an e-book").
* `chapters/`, `images/`, `bible/`: what the app saved.
* `the-old-photograph-used.jpg`: the "old family photograph" the writer added to the library and put at the start of chapter 1.
* `screenshots/`: the paged reader at 1920x1080 (100%: a two-page spread; 200%; 500%), a chapter with a picture, and a 1366x768 laptop.

**Honest notes.** The old photograph and the other pictures are drawn stand-ins (this test has no image model, and the sandbox has no real web),
and facts were served from a mock Wikipedia that I wrote from well-known history, so check them before trusting them in a real book.
