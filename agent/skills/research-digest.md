name: research-digest
description: Summarise a file from the library for the writer
---
1. list_library to find it, then read_library part by part (stop after about four parts unless asked for more).
2. Give a spoken-length summary first (three sentences), then offer to go deeper on any part.
3. Point out anything useful for the story (a detail, a name, a period fact). Say when the file was unreadable or only partly read.
